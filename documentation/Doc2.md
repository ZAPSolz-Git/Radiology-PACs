# Post Processing Features

## Viewer - 2D

**Status:** STANDARD

### Description

The system provides a wide range of tools for image manipulation and annotation, including:

#### Basic Tools

- Select, Pan and Zoom, Zoom, Rotate
- Clockwise, Rotate by Small Angle, Flip Right/Left, Invert Image Contrast, Slice
- Reversal, Reset View, Magnifier, Crosshair

#### Annotation Tools

- Circle, Rectangle, Polygon, Line, Pixel, Angle, Arrow, Text, Remove Selected Annotation

#### Windowing

- Manual WW/WL (Window Width / Window Level) Adjustment

#### Layout Options

- Page Layout Configuration
- Image Layout Configuration

#### Display Options

- **Show/Hide:** Four-Corner Information, Color Bar, Ruler, Crossline, GSPS (Grayscale Softcopy Presentation State) Status

#### Comparison Tools

- Compare Series, Image Locator on Scout

#### Batch Tools

- Play Series, Adjust Playback Speed, Play in Loop, Batch From/To, Select All Images, Clear Batch, Set Image Interval

#### Saving and Output

- Save Image, Save As, Send to Film

## Filming

**Status:** STANDARD

### Description

The Filming module provides a range of tools and settings for customizing and managing image layout and output. Available options include:

- Select / Select All Images, cancel selection
- Zoom/Pan, Rotate Clockwise / Anticlockwise
- Flip Right/Left, Flip Up/Down, Invert Image Contrast, Rotate Small Angle, Reset, Delete Image, Reverse Slice Order, Show/Hide Overlay

#### Page Configuration Options

- **Apply Page Orientation:** Apply to either a single page or all pages
- **Apply Page Layout:** Apply to either a single page or all pages
- **Multiple Layouts:** Users can create and save multiple custom layouts for different use cases

#### Printing Options

- Printer Selection, Number of Copies, Print Priorities: High, Medium, Low, Clear Print Job, Print Preview, Printer Settings, Print Queue, Print

## Post Process

**Status:** STANDARD

### 1. 2D

The images can be viewed. A multi layout option for viewing is available. Tools like Pan, Zoom, Rotate Clockwise, Rotate, Flip - Right/Left, Inverse Image, Sort by Instance ID, Reset, Magnifier, Crosshair, Circle, Rectangle, Polygon, Line, Pixel, Angle, Arrow, Text, delete also measurements options are available.

### 1. Film

Film - The system includes Layout-templates, layouts, printer, priorities, copies, locator image, mark as location, associated selected images, overlay, color bar, rule, true size, settings (film overview), and printing task, printing management.

### 2. MPR

MPR offers multiple options like Batch, Curve (Tracing), Thickness, and Compare series.

### 3. 3D

3D has options for manual tracing, creating VR images and bone removal etc.

## Import/Export

**Status:** STANDARD

### Description

**Export:** Patient data can be exported to a USB drive or burned to a CD directly from the main console by selecting the patient's name and choosing the export option.

**Import:** To import patient data into the main console, open **Daily Service**, select **System Configuration**, and then select **Patient** and then choose **Import**. Select the Path and import the desired data.

## Additional Feature Descriptions

| Feature | Description | Remarks |
|---------|-------------|---------|
| **2D Viewer** | A 2D viewer in CT displays axial, sagittal, and coronal images slice by slice, allowing detailed evaluation of anatomy and pathology. It supports tools like zoom, pan, WW/WL adjustment, annotations, and measurements for accurate diagnosis. | **STANDARD** |
| **3D Post-Processing** | A 3D post-processing tool in CT reconstructs cross-sectional images into 3D views, enabling detailed visualization of anatomy and pathology. It enhances diagnostic accuracy, surgical planning, and interventional guidance. | **STANDARD** |
| **Auto Vessel Analysis (AVA)** | Auto Vessel Analysis (AVA) in CT is an advanced tool that automatically segments, visualizes, and measures blood vessels in 2D/3D from contrast-enhanced scans. It enables rapid assessment of stenosis, aneurysms, and vessel anatomy, enhancing diagnostic accuracy and workflow efficiency. | **STANDARD** |
| **MPR (Multiplanar Reconstruction)** | MPR (Multiplanar Reconstruction) converts axial CT images into other anatomical planes—sagittal, coronal, and oblique (user-defined angles). It supports advanced viewing modes like AIP, MIP, and MinIP, along with tools such as Curve (tracing), Batch, Thick, Line, and Compare for enhanced analysis and workflow flexibility. | **STANDARD** |
