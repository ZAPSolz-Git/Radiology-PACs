🔐 1. LOGIN & USER MANAGEMENT (VERY IMPORTANT)
1.1 User Creation & Role Assignment
•	Admin can create logins for:
o	Technicians
o	Quality Analyzers (QA)
o	Radiologists
o	Hospital / Center users
o	Sub-admins (optional)
•	Each user is assigned a role-based access level.
________________________________________
1.2 Role-Based Access Control (RBAC)
•	Admin defines what each role can see and do:
o	View / Edit / Delete permissions
o	Upload / Download permissions
o	Chat permissions
o	Billing visibility
•	Feature authority can be:
o	Enabled
o	Disabled
o	Limited per user or per role
________________________________________
1.3 Login Security
•	Secure login with:
o	Username & password
•	Account controls:
o	Activate / Deactivate user
o	Lock account after failed attempts
o	Password reset control
________________________________________
1.4 Login Activity & Audit Logs
•	Admin can view:
o	Login time
o	Logout time
o	IP/device (optional)
•	Full audit trail for:
o	Case edits
o	Report changes
o	Billing changes
________________________________________
📊 2. WORKFLOW MONITORING & ALERTS
2.1 Real-Time Workflow Dashboard
•	Admin dashboard shows:
o	Total cases today
o	Pending cases
o	Reported cases
o	Emergency cases
•	Live view of:
o	Which doctors are online
o	Which technicians are active
________________________________________
2.2 Pending & SLA Monitoring
•	Admin can see:
o	All pending cases
o	Delayed reports
o	SLA breach alerts
•	Color-coded status:
o	Green – On time
o	Orange – Near SLA
o	Red – SLA breached
________________________________________
2.3 Automated Alerts
•	Alerts triggered for:
o	Emergency cases
o	Delayed reporting
o	Doctor non-response
•	Alerts via:
o	System notification
o	Email
o	WhatsApp (configurable)
________________________________________
💰 3. BILLING & REPORTS PANEL (DETAILED)
3.1 Billing Configuration
•	Admin can configure billing:
o	Modality-wise (CT / MRI / X-Ray)
o	Study-wise pricing
o	Emergency surcharge
o	Night / holiday pricing
•	Different rates for:
o	Different hospitals
o	Different doctors
________________________________________
3.2 Case-Based Billing
•	Automatic billing generated per case:
o	Date
o	Study type
o	Assigned doctor
o	Reporting status
•	Billing linked to:
o	Final report completion
o	QA approval
________________________________________
3.3 Doctor Payout Management
•	Admin can:
o	Track doctor earnings
o	Define payout rules (per case / per study)
o	Generate doctor-wise payout reports
•	Monthly / weekly payout summary available.
________________________________________
3.4 Hospital / Client Billing
•	Admin can generate:
o	Hospital-wise invoices
o	Date-range billing reports
•	Invoice formats:
o	PDF
o	Excel
•	GST / tax support (optional).
________________________________________
3.5 Payment Tracking
•	Admin can mark:
o	Paid
o	Pending
o	Partial payments
•	Payment modes:
o	Bank transfer
o	UPI
o	Cash (manual entry)
________________________________________
3.6 Billing Reports & Analytics
•	Reports available:
o	Daily / Monthly revenue
o	Modality-wise income
o	Doctor-wise cost
o	Profit margin analysis
________________________________________
